# Rock Paper Scissors Game

A console-based Rock Paper Scissors game written in C++.

## Features

- Play against the computer
- Choose the number of rounds (1-10)
- Random computer choices
- Round-by-round winner display
- Score tracking
- Final game result
- Replay option

## How It Works

The player chooses:

1. Rock
2. Paper
3. Scissors

The computer randomly selects a choice.

Rules:

- Rock beats Scissors
- Scissors beats Paper
- Paper beats Rock

The winner is calculated after each round, and the final winner is determined by the total score.

## Technologies Used

- C++
- Standard Library (`iostream`, `cstdlib`, `ctime`)
